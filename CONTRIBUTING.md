# Contributing

Use Node.js 22+ and pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Before opening a focused pull request, run `pnpm check` and test your changes
in an Obsidian test vault. Describe what changed and how you tested it.

Preserve existing note links and user-written content. Use synthetic examples;
never commit personal vault data, credentials, or generated build files.
